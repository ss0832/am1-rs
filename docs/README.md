# Documentation

Seven documents, and they do not layer neatly by audience — the periodic and divide-and-conquer
notes are reference *and* theory *and* a list of what will bite you. So this index routes by
question rather than by document.

## Start here

| If you want to… | Read |
|---|---|
| run a calculation from Python or ASE | [`python-api.md`](python-api.md) |
| call the crate from Rust | [`rust-api.md`](rust-api.md) |
| know whether a capability exists, and how well it was measured | [`scope.md`](scope.md) |
| know what AM1 and RM1 cover, and which elements | [`methods.md`](methods.md) |
| set up a periodic cell, or read a phonon result | [`pbc.md`](pbc.md) |
| run something too large for one SCF | [`divide-conquer.md`](divide-conquer.md) |
| know what the code actually computes, term by term | [`theory.md`](theory.md) |
| see what changed, and what it cost to find out | [`../CHANGELOG.md`](../CHANGELOG.md) |

The command line is documented in the [README](../README.md#cli), and `am1-rs --help` lists every
flag.

## The three that are worth reading before you trust a number

- **[`scope.md`](scope.md)** is the canonical capability matrix, and each entry says *what was
  measured* rather than what was intended. Where a capability is partial, the partial part is
  named. It is the right place to check a claim made anywhere else, including in this
  documentation.
- **[`pbc.md`](pbc.md#limitations)** — the limitations section, not the setup section. Several
  quantities are three-dimensional by construction (`ε_∞` and LO–TO splitting are the two that
  catch people), a charged cell in 1D or 2D needs an explicit convention before it means anything,
  and `max_image_overlap` is the diagnostic that says whether NDDO's orthonormal-basis assumption
  survives your cell at all. Since 0.2.3 one limitation enforces itself: a **response** on a
  partially occupied ground state
  [raises rather than answering](pbc.md#fractional-occupations-are-refused-not-approximated),
  because the coupled-perturbed equations have no term for it. Smearing is unaffected — the check
  reads the converged occupations, not the smearing width.
- **[`divide-conquer.md`](divide-conquer.md#what-is-linear-and-what-is-not)** — the first section,
  which states precisely which parts of the calculation became linear and which did not. "Linear
  scaling" without that qualification is a claim the method does not make.

## Conventions shared by all of them

**Units.** Internally eV and Bohr. The Rust API is eV/Bohr; the Python native API is Hartree and
Bohr for molecular functions and **eV/Å** for `pbc_point` and `divide_conquer`, whose consumer is
ASE; the ASE calculator is eV, Å and eV/Å³ throughout. The full contract is at the end of
[`scope.md`](scope.md#units-at-the-boundary).

**Measured, not asserted.** Numbers quoted in these documents come from tests in `tests/`, and the
test is usually named beside the number. Where something is an operation count rather than a
stopwatch measurement, it says so — the development machine is loaded enough that wall-clock
comparisons of small differences are not trustworthy, and claiming otherwise has been a mistake
here before.

**Struck-through entries are history, not omissions.** `pbc.md`'s limitations list keeps closed
gaps with a line through them and the release that closed them, so the list reads as a record
rather than a boast. A stale *negative* claim is the failure mode these documents have had most
often: something gets implemented and the prose still says it is missing.

## Third-party material

[`../THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md) covers the bundled *data* — antechamber's
BCC parameters, MOPAC-derived values, PySEQM-derived RM1 parameters — with a per-directory
`README.md` under `third_party/` saying which file came from where and what was changed.
[`../THIRD_PARTY_LICENSES.md`](../THIRD_PARTY_LICENSES.md) covers the linked Rust *code*: 112
crates end up statically inside `_native.pyd` and the CLI binary, which makes every distribution a
copy of each. It is generated by `tools/collect_dependency_licenses.py` and CI fails if it drifts.
